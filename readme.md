## Финальная домашняя работа по автоматизации тестирования API
### Задание:
Автоматизировать два сценария на сайте https://rickandmortyapi.com и https://reqres.in
>Тест 1 (https://rickandmortyapi.com)
>- Найти информацию по
   персонажу Морти Смит
>- Выбрать из ответа последний эпизод, где появлялся Морти
>- Получить из списка последнего эпизода последнего персонажа
>- Получить данные по местонахождению и расе
   этого персонажа
>- Проверить, этот персонаж той же расы и находится там же где и Морти

>Тест 2 (https://reqres.in)  
**Предусловие**  
>Создать в проекте файл
с расширением .Json  
 ```{ "name": "Potato" }```  
>- Создать пользователя, Body в запрос передать из ранее созданного файла, поменяв name и добавив поле job 
```{"name":"Tomato", "job":"Eat maket"}```
>- Проверить статус-код ответа: 201
>- Поле name созданного пользователя имеет значение: ```"Tomato"```
>- Поле job созданного пользователя имеет значение: ```"Eat maket"```

#### **Стек:**
1. Java
2. Maven
3. JUnit5
4. Rest Assured
5. Cucumber
6. Allure


#### **Запуск:**
>Запуск тестов из командной строки: `mvn clean test`  
>Генерация и открытие **Allure отчета** из командной строки: `mvn allure:serve`
